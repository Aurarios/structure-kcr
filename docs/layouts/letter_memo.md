# letter_memo

Official letter / memo: letterhead with logo, date, reference no, salutation, body paragraphs, a
closing and a signature block. Trains `form_label`/`form_value` header + `signature` + body `text`.

**Page geometry**
- Width ~1150px; margins 80–130px; 1 column; left-aligned.
- Body 16–22px.

**Block sequence**
1. `image` — letterhead `logo` (top-left or centered) + `title` organization name.
2. `caption`/`text` — address / contact line.
3. `form_label`/`form_value` — "លេខ:", "កាលបរិច្ឆេទ:" reference + date rows (often right-aligned).
4. `text` — subject line ("ស្ដីពី…") and salutation ("ជូនចំពោះ…").
5. 2–5 body `text` paragraphs.
6. Closing `text` ("សូមគោរព"); a `signature` image + `caption` name/title block (often right).
7. Optional `stamp` → `image`.

**Real images used:** `logos`, `signatures`, `stamps`→`image`.

**Diversity knobs:** letterhead style, reference-block alignment, paragraph count, signature
position, stamp presence.

**Sampling weight:** 1.0
