# book_page

Printed-book interior page: chapter/heading, flowing body, an occasional figure, running
header/footer and page number. Trains clean printed-book reading (a stated production target).

**Page geometry**
- Book aspect; width ~1000–1100px; generous symmetric margins (90–150px); 1 column (75%) or
  2 columns (25%); justified body common.
- Body 16–22px; serif-like or decorative Khmer fonts up-weighted.

**Block sequence**
1. Optional `caption` running header (book/chapter title, small, top).
2. `heading` — "ជំពូកទី N" and/or chapter `title`.
3. 4–9 `text` paragraphs; occasional `subheading` between them; first paragraph may have a drop-cap.
4. 0–1 real `image` figure with `caption` ("រូបទី N៖ …").
5. `text` page-number footer ("− N −"), centered.

**Real images used:** `photos`, `drawings` (illustrations).

**Diversity knobs:** 1/2 column, justified vs left, drop-cap, figure presence, header/footer
presence, page tint/aging, decorative font.

**Sampling weight:** 2.0
