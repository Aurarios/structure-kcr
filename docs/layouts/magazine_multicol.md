# magazine_multicol

Dense 2–3 column magazine spread with multiple figures and pull-quotes. Stresses multi-column
reading order and figures that span/float across columns.

**Page geometry**
- Width ~1240px; small margins (50–90px); 2 columns (60%) or 3 columns (40%); column gap 20–40px.
- Body 15–20px.

**Block sequence**
1. `title` — large feature headline (may span all columns).
2. `caption` — byline / kicker.
3. Flowing `text` paragraphs distributed across columns; 1–3 `heading`/`subheading` breaks.
4. 1–3 real `image` figures with `caption`, some column-width, some full-width.
5. 0–1 pull-quote rendered as a large-italic `text` block.

**Real images used:** `photos`, occasional `charts`, `portraits` (author/subject headshot).

**Diversity knobs:** 2 vs 3 columns, figure spanning, pull-quote presence, drop-cap on first para,
varied fonts per headline.

**Sampling weight:** 1.5
