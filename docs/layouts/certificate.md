# certificate

Award / diploma / certificate: centered ornate titles, a body of recognition text, signature(s)
and an official seal. Trains centered structure + `signature` + `image`(seal/logo).

**Page geometry**
- Landscape common (width ~1300px); large symmetric margins (90–160px); decorative border;
  tinted/parchment background; centered alignment.
- Body 18–26px; decorative Khmer fonts up-weighted.

**Block sequence**
1. Optional `image` — institution `logo`/emblem (top, centered).
2. `title` — "វិញ្ញាបនបត្រ / សញ្ញាបត្រ" (large, centered).
3. `subheading` — recipient line / award name.
4. 2–3 centered `text` recognition paragraphs.
5. Bottom row: 1–2 `signature` images with `caption` name/role under each; 1 official `stamp` →
   `image` (often overlapping a signature).

**Real images used:** `logos`/emblems, `signatures`, `stamps`→`image`.

**Diversity knobs:** portrait vs landscape, border style, seal/signature count and overlap,
background parchment, gold/decorative title font.

**Sampling weight:** 1.5
