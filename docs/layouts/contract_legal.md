# contract_legal

Contract / legal document: numbered articles and sub-clauses, dense body, signature blocks and a
stamp. Trains deep `heading`/`subheading`/`list_item` nesting + multiple `signature` blocks. Mirrors
the RFA/RFI-style legal docs used in earlier testing.

**Page geometry**
- Width ~1200px; margins 70–120px; 1 column; justified body common.
- Body 15–20px.

**Block sequence**
1. `title` — contract/decree title (centered); `caption` reference number/date.
2. `heading` — "មាត្រា N / ប្រការ N" article headers.
3. Under each article: `text` body and/or `subheading` ("N.N") sub-clauses, often as `list_item`
   ("ក. …", "១. …") nested items.
4. Closing `text` ("ធ្វើនៅ … ថ្ងៃទី …").
5. Signature blocks: 1–3 `signature` images, each with `caption` name/role; 1 official `stamp` →
   `image`, often overlapping a signature.

**Real images used:** `signatures`, `stamps`→`image`, occasional `logos` (letterhead).

**Diversity knobs:** article/sub-clause depth, numbered vs lettered lists, signature-block count
and layout, stamp overlap, justified vs left.

**Sampling weight:** 1.5
