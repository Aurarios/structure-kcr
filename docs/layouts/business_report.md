# business_report

Corporate/NGO report page: headings, body, KPI callouts, charts and tables together. Trains mixed
`image`(chart) + `table_region` on the same page.

**Page geometry**
- Width ~1240px; margins 60–110px; mostly 1 column, occasional 2-column sidebar.
- Body 15–20px.

**Block sequence**
1. `heading` — section title (e.g. "របាយការណ៍ប្រចាំឆ្នាំ").
2. 2–5 `text` paragraphs, interspersed with `subheading`.
3. 1–2 `charts` real `image` with `caption`.
4. 1–2 `table_region` (KPIs / financial summary) — `table_head` row + `table_cell` body.
5. Occasional `list_item` bullet summary.
6. Optional `form_label`/`form_value` callout boxes (e.g. "ចំណូលសរុប: …").

**Real images used:** `charts` (primary), `photos`, `logos` (letterhead).

**Diversity knobs:** chart vs table emphasis, callout boxes, sidebar column, letterhead logo,
number formatting (Khmer/Arabic digits).

**Sampling weight:** 1.5
